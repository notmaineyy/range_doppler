What each control changes
  • Bandwidth: δR = c/(2B). More bandwidth makes a narrower range response. A stationary target stays in the same place.
  • Radial velocity: positive means approaching. fc = 2vr/λ and Δx = vr R₀/V. At +3 m/s, the apparent azimuth shifts +100 m. Residual range walk can spread the energy.
  • Antenna length: full-aperture stripmap azimuth resolution is approximately La/2. A shorter physical antenna illuminates the target for longer.
  • Processed aperture: δxrect ≈ La/(2α). Processing a smaller fraction α broadens azimuth detail, but reduces moving-target range walk.
  • Hann weighting: suppresses azimuth sidelobes while widening the main peak. We normalize the weights so a stationary target remains at 0 dB.
Signal model and limits

This is an idealized point-target deramp/FFT image former. Ideal range compression and stationary range-migration correction are assumed. It does not implement a full raw-data RDA processor.

s(r,t) = sinc[(r + vr t)/δR] exp(j2πfc t − jπKa t²)
Ka = 2V²/(λR₀), x = fV/Ka

The image and profiles share a stationary unit-peak reference. The Doppler map normalizes separately. −20 dB corresponds to 1% of reference power. First-null resolution, full −3 dB width and pixel spacing are different quantities. Hann changes the mainlobe width, so compare the measured width above.

No terrain, noise, speckle or antenna-gain tradeoff is modeled. Slant range differs from ground range. The La/2 relation assumes broadside stripmap with the full beam-limited aperture. Zero padding interpolates the image without improving physical resolution.
